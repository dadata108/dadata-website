# Publication checklist

- [ ] Approve company service descriptions and LinkedIn link.
- [ ] Confirm there are no personal details in the rendered site.
- [ ] Review repository visibility and public source exposure.
- [ ] Review dependency/action versions and generate a lockfile.
- [ ] Run typecheck and production build; fix errors.
- [ ] Test desktop/mobile layouts, keyboard navigation, and contrast.
- [ ] Verify base path, exported assets, anchors, and contact links.
- [ ] Obtain separate publication approval.
- [ ] Enable Pages with GitHub Actions and manually run deployment.
- [ ] Verify live site before any custom-domain work.

No personal profiles, client testimonials, client logos, quantified results, or vendor partnership claims are included.
